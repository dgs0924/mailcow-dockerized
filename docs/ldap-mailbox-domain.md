# 使用 LDAP 手机号生成邮箱

在「身份提供商 → LDAP」中配置：

- 登录字段（Username Field）：`mobile`（以 LDAP 实际手机号属性名为准）。
- LDAP 邮箱域名：`cqzhgz.cn`。
- 保留 LDAP 连接、搜索范围、过滤器及邮箱模板配置；按需启用登录自动创建或用户导入。

须先在 mailcow 中添加并启用 `cqzhgz.cn`，且邮箱模板、域容量与配额允许创建邮箱。LDAP 中 `mobile=13800138000` 的用户使用 `13800138000@cqzhgz.cn` 和 LDAP 密码登录；认证查询使用手机号，邮箱创建与定时同步使用完整邮箱地址。属性映射仍用于选择邮箱模板。

域名留空时沿用原有配置，例如直接使用 `mail` 属性中的完整邮箱地址。本功能不回写 LDAP，不重命名或迁移已有邮箱。手机号变更也不会迁移旧邮箱及邮件；上线前应确认手机号唯一、格式一致。含空格、国家区号等值不会自动清洗成另一号码。

## 验证与上线

本地回归测试：

```sh
docker run --rm -v "$PWD:/workspace:ro" -w /workspace php:8.2-cli-alpine php helper-scripts/dev_tests/test_ldap_mailbox_mapping.php
```

将代码更新到部署目录，按现有部署方式刷新 PHP 服务使代码生效，并在管理页面保存配置。该配置使用现有身份提供商键值表，无须新增数据库表。正式启用批量导入前，先用专用 LDAP 测试用户验证登录创建，再验证已有邮箱登录和定时同步。还须实际验证 IMAP/SMTP 或 SOGo 登录；本地模拟测试不代表生产认证已验收。
